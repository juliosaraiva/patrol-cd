# Expected layout of the patrol-cd runtime image, checked by hack/images/rootfs-check.sh against a
# filesystem assembled from the same scripts and build outputs the Dockerfile uses. Written
# independently of rootfs-setup.sh so a change to either one shows up as a difference.
#
# Columns: TYPE MODE OWNER PATH [TARGET]
#   TYPE   d directory | f regular file | x executable regular file | l symbolic link | absent
#   MODE   octal permission bits ("-" for links and absent paths)
#   OWNER  uid:gid ("-" for absent paths)
#   TARGET link target, exactly as stored
